Tech notes

Built on the pi-mono architecture. Runs locally with zero dependencies (Node built-ins). The four teardowns actually execute in agent-console (port 3220). Teardown capability cards: content-breakdown / brand-breakdown / supply-chain-breakdown / product-breakdown.

Dual-route strategy: this product ships on the PI route (pi-mono). DSH route (desktop + web UI) versions are developed separately.

Source code is private; the finished client is distributed via this page.
