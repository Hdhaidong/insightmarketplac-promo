安装说明

所有 agent 均为纯 Node.js 应用，无外部依赖，本地一键运行。

  1. 从上方 GitHub Releases 下载安装包到本地。
  2. 解压到任意目录。
  3. 安装 Node.js（推荐 LTS 版本）。
  4. 命令行进入解压目录，运行： node server.js
  5. 浏览器打开 README 中标注的本地地址，即可使用中文 Web 界面。
