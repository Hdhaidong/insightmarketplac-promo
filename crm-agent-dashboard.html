客户管线看板

拖拽式看板管理客户阶段，列表支持行内直接编辑。待办任务、预警、待确认建议一屏尽览。

AI 对话

ChatGPT 风格全页对话，会话侧栏、流式回复、审批内联卡片。AI 建议采纳/拒绝一键操作。

业务门户（8 模块）

数据市场 / Agent 市场 / 渠道 / ODM / OEM / 样品 / 库存 / 拍卖，对外展示页。询盘自动进 CRM，不错过任何商机。

在线咨询 Widget

右下角浮动气泡，官网一键嵌入。访客咨询实时接入，话术来自企业知识库。

WhatsApp 模拟器

内置 WhatsApp 对话模拟，测试客服流程不用真号。

零构建部署
