Tech notes

The product line's base is the Target ops workbench (the US 10-platform and European multi-country consoles all derive from it). The static build runs as-is; the AI ops assistant activates after an LLM key is configured.

Dual-route strategy: this product ships on the PI route (pi-mono). DSH route (desktop + web UI) versions are developed separately.

Source code is private; the finished client is distributed via this page.
